# student-dropout-ml-project
CT4101 Machine Learning project

# Project Overview:

Classification question: Can a student’s academic outcome be predicted using demographic, socioeconomic, admission, and academic-performance features?


# Dataset:

Dataset name: Predict Students' Dropout and Academic Success

Source: UCI Machine Learning Repository (Donated on 12/12/2021)

Licence: Creative Commons Attribution 4.0 International (CC BY 4.0) license.

Citation: Realinho, V., Vieira Martins, M., Machado, J., & Baptista, L. (2021). Predict Students' Dropout and Academic Success [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5MC89.



# Project Structure:

01_data_and_baseline.ipynb — notebook 

predict+students+dropout+and+academic+success.zip — dataset file

requirements.txt — required Python packages and versions

.gitignore — files excluded from Git tracking




# Setup Instructions

Python version: 3.13.18

To run the project locally:

1) Download the repository.

2) Open a terminal in the project folder.

3) Create and activate a Python virtual environment:

  python3 -m venv .venv
  source .venv/bin/activate

4) Install the required packages:

  pip install -r requirements.txt


   

# Run Instructions

Open the notebook using:

  jupyter notebook 01_data_and_baseline.ipynb

Run all cells from top to bottom.

The dataset ZIP file must be in the same folder as the notebook.
